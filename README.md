# AI Question Index

一个以“长期问题”而不是“新闻流”为单位的全球 AI 前沿判断账本。

在线地址：https://eziorongwork-weee.github.io/codex-test-Knowme/

## 产品定义

每天从全球 AI 信息中，只提取足以改变长期判断的新证据。

网站目前围绕 7 个长期问题：

1. AI 能力增长是否仍在加速？
2. Agent 可以被独立托付多久？
3. AI 能否参与创造下一代 AI 和科学知识？
4. AI 能否建立世界模型并进入物理世界？
5. 前沿智能是否正在变成廉价商品？
6. 我们能否理解、监督和控制更强的模型？
7. AI 是否已经改变真实生产率和组织结构？

## 编辑纪律

- 每日最多展示 3 条“答案变化”
- 没有关键新证据时，明确显示“今天没有变化”
- 不再使用“已回答 62%”一类伪精确百分比
- 每个问题展示当前答案、判断置信度、证据等级与反证条件
- 公司只是路线和证据提供者，不是网站的信息架构

## 输入范围

每日核心监控：OpenAI、Anthropic、Google DeepMind、Meta/xAI、DeepSeek、Qwen、Moonshot AI、智谱 GLM。

其他公司、实验室、论文和独立评测只在出现重大模型、独立复现、真实部署数据或重要反例时进入。

## 证据等级

1. 公司主张
2. 技术报告
3. 独立验证
4. 真实部署数据
5. 行业共识

首页内置轻量证据提交入口。当前提交保存在浏览器本地待审核队列，后续可接入数据库、GitHub Issue 或内部工作流。
